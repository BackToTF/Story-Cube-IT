# Session Runbook - Pilot I&D

## Ruoli gruppo (2-3 persone)

- Facilitator: conduce tempi, regole, debrief
- Content owner: prepara prompt, carte, esempi
- Documenter: raccoglie output e feedback

## Checklist pre-sessione

1. Definire messaggio I&D della sessione in una frase.
2. Scegliere una meccanica primaria e un fallback.
3. Preparare materiali minimi: prompt, timer, board di raccolta.
4. Eseguire dry run di 15 minuti.
5. Verificare strumenti tecnici (audio, chat, condivisione schermo).

## Script facilitatore

1. Apertura
- Oggi giochiamo per esplorare inclusione e collaborazione in contesti IT.

2. Ingaggio
- Ogni intervento deve aggiungere una prospettiva, non solo una risposta.

3. Debrief
- Quale prospettiva non avevamo considerato prima?
- Cosa cambia nel nostro modo di lavorare da domani?

## Rischi e mitigazioni

- Rischio: discussione superficiale
- Mitigazione: almeno 3 domande di debrief obbligatorie

- Rischio: calo di energia
- Mitigazione: round brevi e rotazione ruoli

- Rischio: problemi tecnici online
- Mitigazione: fallback su chat + polling
