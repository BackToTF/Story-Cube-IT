# Roadmap di sviluppo

## Fase 1 - Definizione del format

- scegliere la meccanica base
- definire durata e numero di giocatori
- fissare il valore educativo e narrativo

## Fase 2 - Prototipo fisico

- creare un primo mazzo di carte prompt
- definire una scheda facilitatore
- testare la sessione in una prova rapida

## Fase 3 - Validazione

- raccogliere feedback di facilitatore e giocatori
- semplificare regole e materiali
- scegliere se introdurre una versione digitale opzionale

## Fase 4 - Packaging

- preparare il kit finale
- definire un manuale breve per il facilitatore
- valutare eventuale stampa o produzione di carte
