# Bozza mazzo carte prompt - versione 6 fasi

Questa versione e allineata all'Excel e usa testi semplici, adatti a bambini, con collegamenti logici tra le fasi.

## 1. Fase Personaggio (6 carte)

- P01 - Un bambino curioso.
- P02 - Una bambina coraggiosa.
- P03 - Un inventore gentile.
- P04 - Un'amica che ascolta tutti.
- P05 - Un fratello maggiore responsabile.
- P06 - Una guida del villaggio.

## 2. Fase Luogo (6 carte)

- L01 - Nel parco del quartiere.
- L02 - In una biblioteca colorata.
- L03 - In una scuola di magia.
- L04 - Nel bosco vicino casa.
- L05 - In una piazza piena di giochi.
- L06 - In un laboratorio creativo.

## 3. Fase Oggetto (6 carte)

- O01 - Una mappa con indizi.
- O02 - Una chiave dorata.
- O03 - Uno zaino con strumenti utili.
- O04 - Una lanterna luminosa.
- O05 - Un libro di idee.
- O06 - Una scatola dei messaggi.

## 4. Fase Problema (6 carte)

- R01 - La strada giusta non si trova.
- R02 - Il gruppo litiga su cosa fare.
- R03 - Un amico si sente escluso.
- R04 - Un oggetto importante sparisce.
- R05 - Sta arrivando la pioggia forte.
- R06 - Il tempo per finire sta per scadere.

## 5. Fase Soluzione (6 carte)

- S01 - Il gruppo si ferma e ascolta tutti.
- S02 - Si divide il compito in piccoli passi.
- S03 - Si prova un'idea nuova insieme.
- S04 - Si chiede aiuto a chi e piu esperto.
- S05 - Ogni bambino usa il suo talento.
- S06 - Si trova un piano semplice per tutti.

## 6. Fase Finale (6 carte)

- F01 - Il gruppo risolve insieme.
- F02 - Ogni personaggio aiuta con un talento.
- F03 - Si trova una soluzione nuova.
- F04 - L'amico escluso torna al centro.
- F05 - Il problema diventa una lezione.
- F06 - La storia finisce con una festa.

## Uso rapido in sessione

1. Ogni player seleziona 1 carta per ciascuna fase.
2. Legge le 6 carte in ordine.
3. Costruisce una mini-storia coerente.
4. Le scelte vengono registrate in Excel per il calcolo archetipo.

## Nota

Le carte sono scritte per favorire coerenza narrativa immediata: Personaggio -> Luogo -> Oggetto -> Problema -> Soluzione -> Finale.
